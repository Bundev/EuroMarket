# Подтверждение телефона

Примените `020_seller_trust.sql` после `019` с резервной копией. Для отката
верните предыдущую версию приложения и оставьте таблицы и триггеры сброса
подтверждения. Если предыдущая версия уже умеет изменять телефон, триггеры
продолжат аннулировать подтверждение при таких изменениях.

Настройте в окружении приложения `SMS_WEBHOOK_URL` (HTTPS-адрес вашего
SMS-шлюза), `SMS_WEBHOOK_TOKEN` (Bearer-токен) и `SMS_VERIFICATION_KEY`
(32 случайных байта в виде 64 шестнадцатеричных символов).
Используйте одинаковый ключ на всех экземплярах приложения. Смена ключа
делает ранее отправленные коды недействительными.

Шлюз принимает POST с JSON-полями `to` (международный телефон) и
`text` (текст сообщения). Он должен возвращать 2xx после приёма запроса
на отправку и не записывать тело запроса в журналы. Без корректной конфигурации
отправка возвращает 503. Код действует 10 минут, один код допускает пять попыток.
Повторная отправка доступна через минуту. Действуют дополнительные часовые
лимиты для аккаунта, номера и IP. Для очистки истёкших лимитов используется
существующий скрипт `scripts/prune-auth-rate-limits.js`.
