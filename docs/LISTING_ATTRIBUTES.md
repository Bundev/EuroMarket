# Характеристики объявлений

Поля определены в `services/listingAttributes.js` и привязаны к существующим
slug `vehicles`, `electronics` и `real-estate`. Дочерние категории наследуют
настройки ближайшего подходящего предка. У определения можно задать тип, варианты
выбора, единицы измерения, границы чисел и флаг `required`. Начальные поля
необязательны. Ключ уже используемого поля задаёт его смысл и тип хранения.
Для поля с другим смыслом или типом задавайте новый ключ.

Примените `021_listing_attributes.sql` после `020`. Для отката верните предыдущую
версию приложения и оставьте таблицу `listing_attributes` для сохранения данных.
При возврате функции после редактирования объявлений предыдущей версией проверьте
соответствие сохранённых характеристик действующим категориям.

Сохранённые поиски с характеристиками и сортировкой требуют миграцию
`022_saved_search_attributes.sql` после `021`. Для отката сохраните новые
столбцы и остановите обработчик публикаций до возврата совместимой версии.
Обработчик предыдущей версии пропускает условия характеристик. Если нужно
возобновить работу старого обработчика, предварительно сохраните состояние
подписок и отключите уведомления для поисков с характеристиками.
