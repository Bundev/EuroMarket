# Модерация отзывов

Перед внедрением проверьте миграцию `024_review_moderation.sql` на копии рабочей схемы. На время обновления остановите приложение и фоновые процессы, которые могут писать в базу. Сделайте резервную копию базы и проверьте возможность восстановления.

В клиенте MariaDB, где уже выбрана нужная база, выполните:

```sql
SELECT DATABASE();
SOURCE database/migrations/024_review_moderation.sql
SHOW COLUMNS FROM reviews LIKE 'moderation%';
SELECT moderation_status, COUNT(*) FROM reviews GROUP BY moderation_status;
SELECT COUNT(*) AS inconsistent FROM reviews
WHERE (moderation_status = 'approved') <> (hidden_at IS NULL);
```

Для последнего запроса ожидается 0. Ранее видимые отзывы получают статус «Одобрен», ранее скрытые — «Отклонён». После успешной проверки запустите обновлённое приложение.

При ошибке оставьте запись в базу остановленной и проверьте, какие команды успели выполниться. MariaDB фиксирует изменения DDL отдельно. После устранения причины файл можно применить повторно. Для полного отката восстановите предмиграционную копию в отдельной базе и проверьте её, затем переключите на неё предыдущую версию приложения. Если система уже принимала новые записи, сначала сохраните актуальную копию и согласуйте перенос изменений после резервирования.
