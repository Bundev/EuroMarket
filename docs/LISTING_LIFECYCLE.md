# Срок публикации объявлений

Примените `023_listing_lifecycle.sql` после `022`, проверив целевую базу и
создав резервную копию. Миграция заменяет триггер премодерации. Существующие
активные объявления без даты окончания сохраняют бессрочную публикацию до
явного продления или следующего одобрения. Даты новых публикаций хранятся в UTC.

Истечение сразу скрывает объявление из публичных разделов. Фоновое задание
проверяет сроки раз в минуту небольшими партиями. Если у объявления есть
принятая сделка, архивирование откладывается до её окончания, чтобы стороны
могли завершить сделку. После ручного архивирования восстановление всегда
проходит премодерацию. После истечения продление может восстановить только
ранее одобренную неизменённую версию.

Для отката остановите приложение и его обработчик публикаций. Восстановите
только определение триггера `trg_listing_moderation_guard` из `009`, затем
запустите предыдущую версию. Сохраните новые поля и таблицу истории запросов.
Уже архивированные объявления останутся в архиве. Перед запуском старой версии
дождитесь обработки истёкших объявлений без открытых сделок. Старая версия
не фильтрует по сроку, поэтому активные записи с истёкшим сроком могут снова
стать видимыми.
