# Администрирование EuroMarket

## Миграция

До запуска обновлённого приложения выполните 005_admin_moderation.sql в выбранной рабочей базе через доверенный SQL-клиент с поддержкой DELIMITER, например HeidiSQL или клиент MariaDB. Сначала должны быть применены миграции 001–004. Нужны права CREATE, ALTER и TRIGGER.

Миграция добавляет поля ограничения публикации, таблицы жалоб и журнала, а также обновляет триггер уведомлений. Повторный запуск допускается. Существующие пользователи и объявления не удаляются. До применения сохраните резервную копию базы.

Разблокировка пользователя не публикует объявления и не снимает ограничения объявлений автоматически. Ограничения публикации снимаются отдельно в панели администратора.

Принятие жалобы фиксирует решение модератора. Ограничение публикации выполняется отдельно через управление объявлением.

## Первый администратор

1. Создайте обычную учётную запись через регистрацию с собственным уникальным паролем.
2. Через доверенный доступ к MariaDB найдите эту запись по email и проверьте её ID, имя и статус.
3. В отдельной транзакции назначьте роль только проверенной записи. Замените ID и email в примере своими значениями.

    START TRANSACTION;
    SELECT id, name, email, role, status
    FROM users
    WHERE id = 123 AND email = 'your-existing-account@example.com'
    FOR UPDATE;

    UPDATE users
    SET role = 'admin'
    WHERE id = 123
      AND email = 'your-existing-account@example.com'
      AND role = 'user'
      AND status = 'active';

    SELECT ROW_COUNT() AS changed_accounts;

Выполняйте COMMIT только если выбрана нужная запись и изменена ровно одна учётная запись. Иначе выполните ROLLBACK. Доступ к /admin появится при следующем запросе: роль проверяется по базе.

Пароли не меняются. Общедоступного маршрута назначения роли нет.

## Проверки

Из корня проекта выполните node tests/admin.integration.js. Тест подключается только к euromarket_test, применяет миграции там и откатывает тестовые записи. Общий помощник миграций сохраняет актуальную версию триггеров при регрессионных проверках.
